This project aims to provide a new feature to apartment searching in tokyo. Search by comute time. We have already made a cli tool that calculates all the possible stations the user can reach starting from a certain station.

Our next goal is to build a web application can scrape data about apartments for popular real estate websites in Tokyo based on filters and store the data in a database for caching. We should only scrape at the user's request.

Keep in mind this is a local project. No need for too much complexity
